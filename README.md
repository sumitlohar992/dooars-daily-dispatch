# Dooars Daily Dispatch

Build a mobile-first news aggregation and publishing application named "dooars News" (inspired by regional news platforms like News18 and Aaj Tak). The application should feature a clean, modern, and user-friendly interface using a color palette of Sky Blue and Deep Blue.

### 1. Color Palette & Design

- Primary Color: Deep Blue (for headers, navigation, and brand accents)

- Secondary/Accent Color: Sky Blue (for buttons, highlights, active tabs, and interactive elements)

- Background: Clean white/off-white for high readability

- Typography: Modern, bold headings with clear, legible body text suitable for reading articles.

### 2. Core User Roles & Features

The app should support two main roles:

- Readers / General Public: Can browse news categories (Local, National, Politics, Sports, Entertainment, etc.), read articles, view embedded images/videos, share news on social media, and search for specific topics.

- Reporters / Contributors (Anyone can upload): A dedicated submission portal or "Upload News" button where users can easily submit their own news stories, attach images/videos, add a headline, write a description, and select a category. (Submitted news can either go live immediately or enter a simple moderation queue).

### 3. Key Screens & Navigation

- Splash & Login/Signup Screen: Easy onboarding with phone number/Google sign-in.

- Home Screen:

  - Top breaking news ticker or featured banner carousel.

  - Category tabs (All, Local, West Bengal/Dooars, National, etc.).

  - Infinite-scroll news feed with thumbnail, title, timestamp, and author name.

- Article Detail Screen: Large featured image, headline, author details, full text body, share buttons, and a comment/reaction section.

- Upload News Screen (For Creators): A simple form with fields for Title, Category selection, Image/Video upload, and Rich Text Body, plus a prominent "Publish News" button.

- Profile Screen: User details, bookmarks/saved articles, and a history of news articles uploaded by that specific user.

### 4. Technical Requirements

- Responsive and fast-loading mobile layout (iOS and Android compatible).

- Intuitive bottom navigation bar (Home, Categories, Upload, Saved, Profile).

- Smooth transitions and easy-to-use navigation so that non-tech-savvy users can easily read and upload news.
